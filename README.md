# Student Exam Pass Classifier

A machine learning classification project built with Python and scikit-learn that predicts whether a student will pass or fail based on study hours and attendance percentage.

## Files
- `train_model.py`: Trains a RandomForestClassifier and exports `model.pkl`.
- `predict.py`: Loads the saved model to evaluate new student inputs.
- `model.pkl`: The serialised machine learning model.
